# Zenith Shop 👕🛍️

Zenith Shop es un proyecto web personal desarrollado para practicar tecnologías de desarrollo web. Incluye una interfaz de tienda de ropa y un sistema de inicio de sesión y registro de usuarios con PHP y una base de datos.

El proyecto se centra en la estructura de páginas web, el diseño con CSS, la interacción con JavaScript y el procesamiento de formularios en el servidor.

## 📸 Vista Previa del Proyecto

- **Landing / Tienda:** Interfaz moderna y minimalista con catálogo de productos dinámicos, sección de beneficios de compra y blog de tendencias.
- **Sistema de Autenticación:** Módulo con interfaz dinámica para alternar entre *Iniciar Sesión* y *Crear Cuenta* sin recargar la página.

### 🔐 Inicio de sesión y registro
- Formulario para iniciar sesión.
- Formulario para crear una cuenta.
- Validación básica de campos mediante atributos HTML.
- Envío de los formularios a scripts PHP para procesar el acceso y el registro.
- Integración con una base de datos para almacenar información de usuarios.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** estilos, distribución de elementos y diseño adaptable.
- **JavaScript:** interactividad del lado del cliente.
- **PHP:** procesamiento de formularios de inicio de sesión y registro.
- **Base de datos:** almacenamiento de usuarios.
- **Google Fonts:** tipografías utilizadas en la interfaz.
